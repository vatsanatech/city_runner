# City Runner Flutter plugin

City Runner opens from the current Club Games grid beside Ludo, Bluff and Pen Fight. It launches the existing Godot4.6 3D game natively through the Android plugin. Existing Club assignments, authentication and other game navigation stay unchanged. The legacy experiment-based Games screen/home row was removed upstream; this integration follows the current Club grid. The native City Runner card also stays available on the assigned Club Games page when the separate AI-game catalogue fails or is disabled; that catalogue retains its error/retry and existing gates. The chooser uses the root navigator so persistent STAGE controls cannot cover it.

Only the pinned official Godot engine and small bootstrap/class caches are bundled. City art/maps download after selection, with byte size, progress, cancellation, retry, verification, caching and city-only removal. Rohtak requires shared resources plus Rohtak; other cities download only when selected. All15 playable cities, including7 Haryana cities, retain the existing scenic prototype art and fidelity labels. Catalogue entries are not presented as completed cities.

## Normal preprod build

Use Flutter3.44.9, matching current main/CI, with the repository's existing normal preprod environment and generated artifacts. Do not change existing dependency versions, GrowthBook, analytics, DI, subscriptions or CI to make this feature build.

```sh
flutter pub get
flutter build apk --debug --flavor dev --dart-define=app_environment=dev
```

`dev` names the native app STAGE PREPROD; the normal Envied configuration supplies API URLs. City content defaults to the verified STAGE-owned HTTPS manifest at `https://media.stage.in/scripts/city-runner/android/20261026-inprocess-52a4b78ab98a/manifest.json`. The October26 version publishes only the18 referenced packs/manifest objects, preserving relative paths and immutable cache headers. All18 objects (462,380,879bytes) passed anonymous full-body byte-length/SHA-256 verification for this revision. The shared game pack includes the colour, water, pause, portrait-framing, obstruction-aware traffic and T-shirt/motion and yellow-barricade updates. The seven Haryana packs also include three existing static bystander models so the player outfit does not replace everyone in the crowd. The manifest exposes 15 playable cities; unreferenced legacy packs are never requested. `CITY_RUNNER_MANIFEST` can override that URL at build time. An explicitly empty value shows availability information. No localhost server or flag override is used for normal app acceptance.

STAGE consumes this package from `https://github.com/vatsanatech/city_runner.git` at a full commit SHA in its `pubspec.yaml`. Plugin source is maintained here; the STAGE app keeps only its Games entry and host integration. Run `flutter analyze` and `flutter test` from this repository. Android lint and the full app build run from the STAGE checkout using its existing configuration.

The separate game repository's existing exporter prepares native packs and this plugin's generated bootstrap:

```sh
python3 scripts/export_mobile.py android --packs-only --godot /path/to/Godot \
  --bootstrap-assets /path/to/city_runner/android/src/main/assets
```

Godot renders inside the existing Flutter route through an Android platform view in STAGE’s main process. `MyApplication.kt` is unchanged from main; there is no secondary game Activity/process or host SDK/app-open exclusion. One application-context Godot engine is retained for repeat visits because its normal destruction can terminate the process. Closing frees the game scene and landmark preload references, pauses the renderer and releases audio focus before returning to the chooser; reopening mounts the selected city and creates a fresh scene. The engine itself remains allocated until the app process ends, so this does not promise zero retained memory. Back pauses a run, returns other game screens home and closes home to Flutter without terminating STAGE. Background pauses the engine; foreground requires explicit run resume. STAGE music pauses before native play and stays paused on return.

The earlier isolated matched arm64 release proof measured67.50MiB incremental APK bytes. That is not a STAGE release/Play or installed-size result. The previous full-host device proof used an obsolete July host branch and local content; it cannot establish acceptance of this current preprod build. Native iOS hosting, physical-phone performance/audio, payments and ranked services remain unfinished.
